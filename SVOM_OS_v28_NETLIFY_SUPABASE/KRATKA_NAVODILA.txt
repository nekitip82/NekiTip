SVOM.OS v25 — kratka navodila za objavo

1. SUPABASE
- Odpri svoj Supabase projekt.
- SQL Editor > New query.
- Kopiraj in zaženi vsebino datoteke: supabase_setup_v25.sql

2. CONFIG.JS
- Odpri datoteko config.js.
- Vpiši svoj Supabase Project URL.
- Vpiši svoj Supabase Publishable/Anon key.
- Ne uporabljaj service_role ključa.

3. NETLIFY
- Na Netlify ustvari novo stran ali odpri obstoječo.
- Deploy / Add new site > Deploy manually.
- Naloži VSEBINO te mape oziroma ZIP paket.
- Glavna datoteka je index.html.

4. PREVERI
- Odpri objavljeno stran.
- Preveri prijavo z inicialkami.
- Dodaj testni zapis v Delovodnik.
- Osveži stran in preveri, da zapis ostane.
- Preveri tudi priponko in Načrt dela.

V paketu:
- index.html ........ produkcijska aplikacija
- config.js ......... povezava na Supabase
- supabase_setup_v25.sql ... baza + storage nastavitve
- netlify.toml ...... Netlify nastavitve
- README.txt ........ daljša pojasnila
- SVOM_OS_v25_original_local.html ... lokalna rezervna kopija

Nastavitve SVOM.OS: geslo 123

ARSO WIDGET – POPRAVEK
---------------------
V tem paketu je dodana Netlify Function:
  netlify/functions/arso.js

ARSO widget zato ne kliče več ARSO XML neposredno iz brskalnika,
ampak:
  SVOM.OS -> Netlify Function -> ARSO

To odpravi običajno CORS težavo.

Za posodobitev na Netlify ponovno objavi CELOTNO vsebino tega paketa,
ne samo index.html, ker je potrebna tudi mapa netlify/functions.

Po objavi lahko preveriš:
  https://TVOJA-DOMENA/.netlify/functions/arso?src=coast

Če vidiš XML, proxy deluje.
